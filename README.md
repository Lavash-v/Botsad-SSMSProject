# Назначение
### актуальный код в ветке v2!!!  
База данных предназначена для учёта коллекции растений ботанического
сада. В ней хранится информация о самих растениях, их систематике
(семейство, жизненная форма), происхождении (родина, источник
поступления), размещении (локация, история перемещений), кураторах,
фотографиях и регулярных наблюдениях (полив, цветение, состояние
здоровья)

Что можно:
- вести карточку каждого экземпляра растения по уникальной бирке;
- отслеживать историю перемещений растения между локациями;
- фиксировать наблюдения и изменения состояния здоровья;
- хранить фотографии растений

### Таблицы


 `Families`       Семейства               Семейства растений (Розовые, Ароидные и т.д.)                              
 `LifeForms`      Жизненные формы         Дерево, кустарник, трава, лиана, суккулент                                 
 `Sources`        Источники поступления   Откуда поступило растение (питомник, экспедиция, подарок и т.д.)           
 `Locations`      Локации                 Места размещения: корпус, сектор, стеллаж, участок                         
 `Employees`      Работники               Сотрудники ботанического сада (кураторы растений)                          
 `Plants`         Растения                Карточки растений: названия, сорт, родина, статус, куратор, инвентарный № (бирка)  
 `PlantPhotos`    Фотографии растений     Галерея фотографий, привязанная к растению                                 
 `Transfers`      Перемещения             История перемещений растения между локациями                               
 `Observations`   Наблюдения              Записи о поливе, осмотрах, цветении, состоянии здоровья                    

### Запросы

**По растениям:**
- все растения;
- только русское и латинское название;
- растения конкретного семейства (например, Яснотковые);
- все кустарники;
- растения родом из Азии;
- растение вместе с его семейством;
- растение вместе с его локацией.

**По инвентарному номеру и статусу:**
- найти растение по бирке;
- только активные растения;
- архивные и погибшие;
- сколько растений в каждом статусе;
- растения, поступившие за последний год;

**По кураторам:**
- все растения с указанием куратора;
- все растения конкретного куратора;
- сколько растений у каждого куратора;
- растения без куратора;
- контакты куратора конкретного растения.

**По фотографиям:**
- все фото конкретного растения;
- сколько фото у каждого растения;
- растения без фотографий;
- обложка и количество фото в галерее.

**По перемещениям:**
- история перемещений конкретного растения;
- все перемещения за последний год;
- сколько раз переезжало каждое растение;
- кто чаще всего перемещал растения;
- последнее перемещение каждого растения.

**По наблюдениям:**
- все наблюдения по конкретному растению;
- все цветущие наблюдения;
- записи о болезнях;
- только поливы;
- сводка по типам наблюдений;
- сводка по состоянию здоровья;
- средняя температура и влажность по каждому растению.

**Сводные:**
- общее количество растений;
- полная карточка растения (все данные сразу);
- сколько растений в каждой локации;
- сколько растений по семействам;
- сколько растений по жизненным формам.
